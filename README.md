##  App Purpose

The Social Spark App is built to help people stay connected in simple, everyday ways. It gives users small, thoughtful ideas called “sparks” based on the time of day, making it easier to reach out and interact with others without overthinking it.


##  How the App Works

Using the app is straightforward:

1. The user types in a time of day, like Morning, Afternoon, or Night.
2. The app checks the input using conditional logic (if/when statements).
3. It then shows a matching social suggestion.
4. If needed, the user can tap the reset button to clear everything and start again.


## Features

* A simple input field where users enter the time of day
* Instant suggestions that change based on the input
* A reset button to quickly clear the screen
* Error messages for invalid inputs
* Logcat logging to help track what’s happening in the app


## Example Suggestions

* **Morning:** Send a “Good morning” message
* **Afternoon:** Share a funny meme
* **Dinner:** Call a friend
* **Night:** Comment on someone’s post


##  Error Handling

If the user types something unexpected or incorrect, the app doesn’t crash. Instead, it shows a helpful message asking them to enter a valid time of day.
